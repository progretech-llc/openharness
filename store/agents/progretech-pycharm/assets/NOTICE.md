# Asset provenance

`example-run.png` is Edwin Rodriguez’s original screenshot supplied on 26 October 2026 for this contribution. It shows a Harness worker using Grok with local Qwen3 Coder 30B, alongside the separately installed PyCharm IDE with the same demo folder open. The worker reports script output and launcher success; this is not an embedded IDE or a demonstration of debugger/UI control.
